## Scope

This run adds and verifies a scoped deterministic Playwright E2E for 11.1.6
Execution via Replay. It is a Conversation API E2E, not Agent-operated UI,
not Console live smoke, and not verify-scenario.

The successful execution case is a seeded confirmed execution context E2E. It
uses natural dispatch only to enter `plan_confirmed`, then appends auditable
`plan_preview_proposed` before `plan_confirmed` events through the public
Conversation event API so the confirmed context includes `target_url`. It is
not described as a natural planning happy path.

  messages with `source=execution_gate`.
