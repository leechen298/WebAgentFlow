# Skill Spec

## What a Skill Is

A skill is a reusable automation definition that describes how WebAgentFlow should perform a task. Skills will eventually be versioned, validated, and executable across API, worker, and extension contexts.

## What `steps` Are

`steps` is the ordered list of actions or declarations inside a skill. Each step describes one piece of the automation flow and its inputs.

## Future Step Types

Future versions are expected to support step categories such as:

- browser navigation
- element interaction
- extraction
- conditional branching
- variable assignment
- tool invocation
- assertion and validation
