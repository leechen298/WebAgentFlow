## Decisions Made in This Implementation

- **Unable-to-plan representation**: `AgentDPlannerOutput` with `route_plan=None`,
  `uncertainty` containing the reason, and a `blocking` `ConfirmationRequirement`.
- **Ambiguous candidate threshold**: Count-based — when the top two candidates
  are both `confirmed` AND the second has strong match signals (exact scenario
  or exact page), the selection is flagged as ambiguous.
- **Slot Binding**: Remains future scope. `RouteStep.bound_slots` is always `{}`
  in this MVP.
- **Determinism**: Fully deterministic. No LLM adapter in this package.
