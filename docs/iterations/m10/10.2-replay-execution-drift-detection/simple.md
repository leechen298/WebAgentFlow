# 10.2 通俗版

## 一句话

系统已经“学会了一条路”，10.2 要做的是：让系统照着这条旧路再走一遍。
走得通，就说明这条路还能用；走不通，就告诉用户卡在哪里。

## 为什么要做

10.1 和 10.1.5 已经把 LearnedPath 存下来了，也能在 catalog 里看见。
但现在用户只能看到“系统学过这条路”，还不能验证“这条路今天还能不能
跑”。10.2 就是把 LearnedPath 从记录变成可复用资产。

## 用户看到的体验

1. 打开 LearnedPath catalog。
2. 选择一条 LearnedPath。
3. 输入要重跑的 URL。
4. 点击“重跑这条路径”。
5. 系统打开页面，照着旧步骤执行。
6. 执行结束后，在 drawer 里看到：
   - 重跑结果；
   - 页面是否变化；
   - 哪一步成功或失败；
   - 最终 URL / title；
   - 找不到目标或动作不支持时的友好说明。

## 失败时怎么解释

- `page_mismatch`：这不是当初学会的那类页面。
- `signature_changed`：页面像是同一类，但结构或参数变了。
- `target_missing`：当初记录的按钮或输入框找不到了。
- `unsupported_action`：这类动作当前还不能重跑。
- `runtime_error`：浏览器启动、打开页面或执行过程出错。

## 要守住的边界

Replay 只是“照着旧路走一次”。它不重新学习、不重新规划、不猜用户任务、
不静默重试，也不调用 autonomous run 创建接口。它的结果也不是
`pass_gate`，不是 Supervisor verdict。
